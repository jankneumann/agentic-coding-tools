# Teaching With Repo Token

## Red-Green-Refactor

Write a failing test first, make it pass with the smallest change, then
refactor with the suite green. Record the outcome of each cycle's design
decision under docs/decisions/ so the next agent can see why.

## Generic Advice

Small commits are easier to review than large ones. Prefer clear names over
clever ones and keep functions short.
