## 2026-08-14 — derive-agent-identity-from-registry

### Phase: Implement

**Concurrency via idempotent upserts, not an advisory lock (D9 amended)** — pg_advisory_lock is unreachable through DatabaseClient: no raw execute, rpc() emits named-parameter calls Postgres built-ins reject, and pooled connections make session-scoped locks unsafe.
