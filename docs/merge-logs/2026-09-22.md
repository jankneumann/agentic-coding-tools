### Vendor Review Findings
Both threads **verified and fixed**, both catching a fix that was itself flawed.

- **#604 (P1)** — my first commit anchored `AS_OF` to "now + 1 day". Codex noted that on 2026-12-31 that crosses 2027-01-01 and the clock-skew fixture stops being in the future, silently turning "asserts clock_skew fires" into "asserts nothing". A band-aid with its own expiry date. Superseded by `3bdd4902`, which pins *both* sides: `_git` stamps fixture commits at `FIXTURE_COMMITTED_AT` (2026-01-02) and `AS_OF` is a constant a day later. The 2027-01-01 fixture stays after AS_OF permanently because neither value moves.
- **#589 (P1)** — blanking identity whenever an API key is present is right for a *bound* key and wrong for an unbound one. With a key in `COORDINATION_API_KEYS` and no `COORDINATION_API_KEY_IDENTITIES` entry, `resolve_identity` has only the request fields, so blanking resolves every agent to the `cloud-agent` default: one lock owner shared by all agents, each able to release the others. A loud 403 traded for a silent correctness bug. Fixed by sending the caller's identity first and retrying without it only on the specific refusal message.
