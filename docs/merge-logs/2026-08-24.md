### Defect: vendor review prompt contradicts the review-findings schema

`scripts/vendor_review.py:201-215` instructs vendors to emit
`id, type, criticality, description, resolution, disposition, file_path, line_range`.
`openspec/schemas/review-findings.schema.json` requires
`id, type, criticality, description, disposition, axis, severity`.
**`axis` and `severity` are required but appear nowhere in the prompt**, so a vendor obeying the
instructions produces invalid output.
