### Why #648 came first

`main`'s Security workflow went red on 2026-09-30 having passed on 09-27: ten advisories in
`pyjwt` 2.13.0. Two are not mitigated by anything in this codebase — `CVE-2026-102267`
(`PyJWKClient` followed JWKS redirects without validating the destination) and `CVE-2026-101917`
(unbounded JWKS fetches from an attacker-controlled `kid`). Both land on `cloudflare_access.py:99`,
which constructs a real `jwt.PyJWKClient`.

The algorithm-confusion advisory needs an app mixing symmetric and asymmetric keys, which this one
does — HS256 for SSE tokens, RS256 for Cloudflare — but it was already defended: both decode sites
pin `algorithms=` explicitly. That defence lives in two call sites rather than in the dependency,
so `TestPyJWTFloorIsHeld` names it; a third JWT consumer would not inherit it.

Both plan PRs inherited the failure. #468 appeared green only because its checks predated the
advisory, which is why each was refreshed rather than merged on a stale pass — branch protection is
`strict: false`, so #648 landing does not re-run anything.

### Merge strategy: merge commit rather than the rebase default

`--strategy rebase` failed with *"This branch can't be rebased"*. Both branches carried merge
commits from the `refresh-branch` operations that kept them testable across 761+ commits of drift.

The convention makes agent PRs rebase-merge **"to preserve granular history"**. Rebase being
unavailable, squash would have collapsed #467's seven refinement commits and #468's six into one —
defeating the reason for the rule. A merge commit preserves them and is established practice here:
`main` carries 47 merge commits in its last 200, including `Merge pull request #417` from an
`openspec/*` branch, and `allow_merge_commit` is true.

**The tradeoff worth recording:** `refresh-branch` merges `main` *into* the PR branch, which keeps
CI alive but permanently forfeits rebase-merge. For a long-lived branch needing repeated refreshes
that is a deliberate exchange, not an accident — the alternative, a local rebase and force-push,
preserves the option at the cost of rewriting a branch under review.
