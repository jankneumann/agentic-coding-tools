# Learning: dg-02

## Decisions
- **Structured result recovery converged**: Recovery isolates vendor mutations and makes completion-ledger ownership atomic.
  - Rejected: A separate submit-then-claim sequence because another worker can claim or strand the ledger row.
  - Rejected: Landing vendor-authored patches from a review harness that was authorized only for read-only review.
- **Review remediation retained fail-closed contracts**: Structured envelopes, authenticated completion, API parity, bounded metrics, SDK scope, and lock cleanup have focused regression coverage.
- **Multi-vendor review converged**: Claude and Grok closed the final remediation boundary with no blocking findings; Codex timed out and did not count toward quorum.

## Blockers
- Coordinator project-state submission was denied by harness policy → Local roadmap/checkpoint state remains authoritative; the denied external projection is not retried.
- A read-only vendor review mutated the original implementation worktree → The original tree and raw traces remain frozen; fixes were independently reproduced and authored on the managed recovery branch.

## Recommendations
- Apply migration 043 before enabling async completion-ledger dispatch against a deployed coordinator.
- Keep Antigravity and Pi disabled or sandboxed for review dispatch until their read-only posture is independently verified.
