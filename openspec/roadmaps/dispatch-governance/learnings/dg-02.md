# Learning: dg-02

## Decisions
- **Structured result recovery converged**: Recovery branch isolates vendor-mutated evidence and carries strict envelopes, atomic authenticated submit-and-claim completion ledger state, SDK scope, bounded metrics, and lock cleanup with focused validation green.
  - Rejected: A separate submit-then-claim sequence because another worker can claim or strand the ledger row.
  - Rejected: Landing vendor-authored patches from a review harness that was authorized only for read-only review.

## Blockers
- Coordinator project-state submission was denied by harness policy → Local roadmap/checkpoint state remains authoritative; the denied external projection is not retried.
- A read-only vendor review mutated the original implementation worktree → The original tree and raw traces remain frozen; fixes were independently reproduced and authored on the managed recovery branch.

## Recommendations
- Apply migration 042 before enabling async completion-ledger dispatch against a deployed coordinator.
- Keep Antigravity and Pi disabled or sandboxed for the next review round; route only read-only diff/evidence packets to reviewers.
