# Learning: ri-02

## Decisions
- **Silence in a vendor's terms is recorded as unaddressed**: Every unattended lane that is not permitted names a keyed lane; all four vendors' daemon lanes are unaddressed
- **Every mechanics field carries an evidence level**: All 16 fields are documented or not_observed; none is observed
- **The item is left in progress**: Task 4.1 (host observation) is open and the drift gate fails on it

## Blockers
- Only the Claude CLI is installed in the cloud container and none is signed in → Observation script and host procedure shipped; open as task 4.1
- Legal and documentation hosts for OpenAI, Google Antigravity and xAI are blocked by the network policy → Verdicts rest on repositories and package-embedded documentation; rows marked summarised where relayed

## Deviations
- Plan: Verdicts quoted from each vendor's terms, mechanics observed on a host → Actual: Claude terms read directly; three vendors from product documentation; no host observation (reason: Environment limits)

## Recommendations
- ri-03 and later: a read-only bind of a login store cannot refresh; Codex and Grok need the directory writable
- A refresh inside a sandbox rotates the host's token for Claude and Codex, so do not copy credential files
- Do not dispatch agy on a subscription from the orchestrator until the Antigravity FAQ on wrapping is read in its own text
- Claude subscription dispatch must leave ANTHROPIC_API_KEY unset and not pass --bare, which is documented to become the -p default
- Read vendor-auth-audit.yaml by program and refuse to depend on a field whose evidence is not observed
