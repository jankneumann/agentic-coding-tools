# Learning: ri-07

## Decisions
- **Orchestration is coordination-only; models/store/manifest reused from ri-04/05/06**: orchestrator.py + semantic_adapter.py in the ri-05 skill import the ri-06 OperationStore/manifest/models, ri-05 run_producer, and ri-04 result builders; no result/manifest/operation model is redefined. generate() drives producers into one operation, records each BEFORE the degradable semantic index, finalizes, then projects+writes the manifest.
  - Rejected: A separate refresh-project-context skill duplicating runtime sys.path + CLI wiring
- **One immutable operation per (repo,revision); succeeded=reuse, degraded/failed=resume-semantic-only (D9)**: ri-06 is append-only per producer and content-addressed by revision, so deterministic results are immutable per revision. A succeeded op is reused verbatim; a degraded/failed op re-attempts ONLY the mutable semantic index (never re-runs sealed producers), which can lift degraded->succeeded when the index returns.
  - Rejected: Re-run and re-record all producers on retry (crashes on DuplicateProducerError; regenerates artifacts whose fresh result is then discarded -> lying manifest)
- **Semantic index is the sole degradable producer; check-mode is deterministic-only**: semantic_adapter maps ri-02 code_search outcomes to a SemanticIndexReference: success->SUCCEEDED (revision-pinned), unavailable/error->non-succeeded + exact-search fallback, never raises. refresh-check excludes semantic so its exit code (0/2/1) is a faithful deterministic-drift signal for the ri-10 gate.
  - Rejected: Treat unavailable index as FAILED (would make the CI gate never green)
- **Manifest to gitignored .git-context/, scoped runs never finalize the shared operation**: Manifest is written to repo-relative gitignored .git-context/context-refresh-manifest.json (ManifestPointer needs a repo-relative path; .git is a gitdir file in worktrees) so reruns produce no repo diff. A --producer run is regenerate-and-report only (no durable op, no manifest) so it cannot poison a full refresh.
  - Rejected: Write under a literal .git/ path (fails in linked worktrees)
