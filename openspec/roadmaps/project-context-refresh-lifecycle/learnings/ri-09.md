# Learning: ri-09

## Decisions
- **The isolation levers already existed downstream; ri-09 was threading, not building**: semantic_adapter.py hardcoded --namespace-kind main --namespace-key main while code-search already accepted work_package and gated canonical promotion on the main pair; indexing_policy already enforced read_allow while ri-08 already computed it. Reading downstream code before designing turned an assumed subsystem into a parameter-threading job.
  - Rejected: A third checkpoint() mode in the ri-07 orchestrator -- claims the canonical per-revision operation, so a later refresh at that SHA reuses scope-restricted results
  - Rejected: Parameterizing generate() -- it writes producer outputs into the tracked tree, the exact canonical mutation acceptance outcome 3 forbids
- **Implementer pushback caught a real contract defect the plan missed**: delta_authoritative was prose-only: {freshness: stale, delta_authoritative: true} validated, precisely what D6 exists to prevent. Encoded as if/then, verified failing against the pre-fix schema. A second finding corrected D3's claim that check-mode read-only-ness was 'true by construction' -- the registry gives no such guarantee.
  - Rejected: Letting the implementer edit the authored contract in place -- outside its write_allow, and a one-sided edit breaks the byte-identity promotion depends on
- **Both CI failures were real defects, unreachable by the locally chosen suites**: An undeclared implement-feature -> project-context-refresh cross-skill edge caught by install.sh --check, and a stale derived decision index. docs/decisions/ regenerates from capability-tagged session-log entries and fires on ACTIVE changes, not only at archive time. Neither is reachable by running pytest on the suites a change touches.

- Plan: RED-before-GREEN for the wp-workflow tests → Actual: Tests mutation-checked instead (reason: checkpoint.py had already landed with wp-checkpoint, so a natural RED was impossible; collapsing unmigrated into declared failed 3/3, proving the tests non-vacuous.)
