# Learning: ri-03

## Decisions
- **Read only exact immutable v2 storage**: The query path proves repository, revision, namespace, canonicality, provider fingerprint, and final storage before returning provenance-bearing hits.
- **Prove effective scope as a bounded language intersection**: Principal grants, request narrowing, work-package paths, and deny patterns are composed with exact product-NFA semantics under state and transition-work budgets.
- **Advertise semantic search from body-aware readiness**: CAN_CODE_SEARCH remains false unless a loop-owned runtime reports a usable provider and compatible ready index; unverifiable MCP-only discovery fails closed.

## Blockers
- Live Postgres/pgvector and embedding-provider resources were unavailable → Kept six RI03 and seven upstream cases explicitly resource-gated while 478 mandatory deterministic tests and all structural gates passed.
- Connected GitHub approval service reached its usage limit during draft PR creation → Pushed commit 42a77216 to the feature branch and recorded draft PR creation as a deferred sync action; no alternate route bypassed the approval control.

## Deviations
- Plan: Use bounded heuristic witness expansion for complex glob intersections → Actual: Implemented exact product-NFA language nonemptiness with independent state and transition-work budgets (reason: Independent review found false denials and an adversarial work-amplification path in the heuristic approach.)
- Plan: Publish a stacked draft PR immediately after validation → Actual: Published the branch but deferred PR creation (reason: The connected GitHub approval service rejected the mutation after reaching its usage limit.)

## Recommendations
- ri-06 should represent semantic readiness and resource-deferred outcomes separately from deterministic artifact freshness.
- ri-07 should consume the typed code-search status and RI02 operation identity rather than importing query or indexing internals.
- ri-09 should use exact branch revision and work-package scope identities when it requests branch-local semantic context.
- ri-11 should run semantic convergence only for the final pushed main SHA and must preserve exact-search fallback on any stale, unavailable, or not-configured result.
