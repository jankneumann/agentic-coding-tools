# Learning: ri-11

## Decisions
- **Judgment sits where the size check was, not before the deterministic skips**: is_draft and SKIP_ORIGINS (dependabot/renovate/Jules) run first and return before the judged call is ever made -- those are facts about provenance, not judgments, per the parent proposal's own framing. A call-count test proves decide() is never invoked for a skip-origin or draft PR.
- **The judgment doesn't bypass the existing-reviews check**: has_approval/changes_requested is orthogonal to risk -- it exists to avoid re-reviewing a PR already acted on, regardless of how risky the change is. The judged-eligible branch still falls through into that check before returning eligible, exactly as the original size-eligible branch did.
- **First call site to use the Score primitive**: No prior judged item in this roadmap used Score (all used Choice or Noul). Per the parent proposal's typed contract, ScoreAnswer has (score, confidence, probabilities, legend); this item reads score/confidence via the established _answer_field shim and records them as risk_score/risk_probability -- informational only, never gating. Eligibility itself is decided by the Noul's bare probability against a config-held floor, mirroring triage.py's p >= floor convention (a Noul has no separate confidence field).

## Recommendations
- The skill-workflow capability spec documents a similar arithmetic-proxy candidate (the Complexity Gate) from the prior item; this item found no equivalent candidate in merge-pull-requests beyond the one just replaced.
