# Learning: ri-12

## Decisions
- **Batching granularity is one call per session-log phase, not per file or per decision**: The roadmap item's own wording -- batched as many questions over one session-log phase as shared state -- is explicit. propose_tags_for_archive groups extracted decisions by (phase_name, phase_date) before calling _classify_phase_decisions once per group, with one Choice question per decision keyed by decision_index.
- **The judged and keyword paths share one category universe**: The Choice criteria are derived from keyword_map's own keys, not a hardcoded list of the seven default tags, so a caller passing a custom or reduced keyword map (as this item's own tests do) gets a judgment constrained to that same reduced set.
- **A malformed answer for one decision doesn't discard a phase's whole batch**: Applied the ri-15 Codex-caught lesson proactively this time: _classify_phase_decisions returns a dict keyed by decision_index populated only for decisions whose answer was present, named a recognized capability, and carried a numeric confidence. A missing entry falls back to classify_decision individually without discarding sibling results from the same successful batch.
- **none is not a fallback signal -- it's a confident negative**: A Choice answer of none is a successful, confident classification, not a degradation case -- it is recorded directly as proposed_capability=None with the judgment's own confidence, landing in the no_match bucket exactly like today's no-keyword-match case.

## Recommendations
- Verified ruff check locally before pushing this time, after ri-16 self-inflicted a CI failure on line-length violations that a local lint check would have caught before the push. Also caught mid-session: embedding backticks in a python -c string passed through a double-quoted shell command triggers command substitution and silently strips them -- affected the prose formatting (not the substance) of the ri-15 and ri-16 learning entries already merged; not worth retroactively fixing, but worth avoiding going forward by writing scripts to a file instead of -c for anything containing backticks.
