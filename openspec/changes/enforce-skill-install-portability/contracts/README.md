# Contracts

This change modifies the internal skill-distribution boundary and does not add or change an HTTP API, database schema, event payload, or generated public type.

The executable contracts are:

- the installed payload derived by `skills/install.sh`;
- the static portability diagnostic schema used by the validator;
- the clean-consumer test fixture and smoke-entry-point registry.

OpenAPI, database, event, and generated-type contract sub-types were evaluated and are not applicable.
