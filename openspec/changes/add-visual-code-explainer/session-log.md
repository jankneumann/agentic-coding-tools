### Alternatives Considered
- Scripted explainer emitting every visual form from the graph: rejected because Effort L. Duplicates the atlas view-model and Mermaid emitters; sequence diagrams would be deterministically wrong because the static graph carries no runtime ordering; loses the conversational speed that is the point. Most likely to stall the way codeviz Phase 0 did.
- Fold a question mode into codebase-atlas instead of a new skill: rejected because Effort S and cheapest, but the atlas is specified as a rendering skill that never parses source, and the source-reading fallback is essential. It would also push the atlas SKILL.md toward the 500-line cap and make the trigger overlap worse rather than better.
- Ship a triggers: list per the current canonical spec: rejected because Nothing in the repo reads triggers, and rewrite-skill-frontmatter deletes them wholesale. Writing the trigger condition into the description survives both orderings.

### Trade-offs
- Accepted Only the call tree is machine-verified over Deterministic generation of every visual form because File trees, component trees, and sequence diagrams stay model-authored. The disclosure line makes that boundary visible on every answer rather than hiding it, which is a better honesty/effort trade than building a third renderer.
- Accepted Most answers will be ungrounded in the near term over Blocking the skill on an analyzer coverage fix because The architecture refresh failed with three validator errors during planning, parallel_zones.json is absent, and TypeScript coverage is 0%. Refusing until the graph is fresh would block the fast conversational path indefinitely; usage of the ungrounded path is itself the evidence the codeviz roadmap says its later phases need.
- Accepted Coverage percentages are an optimistic upper bound over Exact path-based coverage because The analyzer records bare basenames, so one graph name can match several on-disk files. Fixing node identity is a separate prerequisite change (issue #275); the reference file states the number is a ceiling.
