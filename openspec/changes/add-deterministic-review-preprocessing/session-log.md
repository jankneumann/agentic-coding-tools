### Decisions
1. **Port OCR's deterministic stages as stdlib Python rather than shelling out to the ocr binary** `architectural: skill-workflow` — Delegate mode does not expose the resolver or the review filter; a Go binary on the core review path is absent from cloud containers; preview and run must share one selection function.
2. **Line resolution anchors on a verbatim existing_code snippet resolved at ingest, no model relocation** `architectural: skill-workflow` — Fixes consensus line drift, gives the ledger a snippet fingerprint, and lets compact re-verify by snippet presence; relocation cost is deferred until the fixture set shows the miss rate.
3. **Fact-check pass runs on the economy tier after raw checkpoint and before synthesis, counted in the round budget** `architectural: review-convergence-safety` — Operator choice at discovery; removals are logged with the disproving line and protected subjects are never removed; failures remove nothing.
4. **Coverage is optional on the payload and binding in the manifest; absent coverage is full coverage** — No existing vendor loses quorum for a field it never emitted; partial coverage limits eligibility per file like the placeholder-only rule.
5. **This change lands before ambient-review-ledger, which rebases onto it** — ambient-review-ledger is planned only (0/33 tasks, no branch); PR #531 landed the gate-time ledger slice this change modifies. Additive edits keep either order mergeable.
6. **Delivery order: fact-check and OCR vendor first, ports after** — Operator's Gate 1 modification; they attack the false-positive pain directly and touch no files the ports touch.

- Model-based relocation on resolver miss: rejected because One call per miss; deferred until fixtures show the miss rate.
- Fact-check on the premium tier: rejected because Operator chose economy tier counted in budget.
