### Requirement: Aggregate process telemetry into a comparable scorecard feed

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-03` and is refined by
`/plan-feature` before implementation.

#### Scenario: A single command emits one JSON record per agent run with all named…

- **WHEN** the roadmap item is implemented
- **THEN** A single command emits one JSON record per agent run with all named metrics populated

#### Scenario: Records from at least two different vendor harnesses normalize to…

- **WHEN** the roadmap item is implemented
- **THEN** Records from at least two different vendor harnesses normalize to the same schema

#### Scenario: The feed backfills from existing stored transcripts, not only from…

- **WHEN** the roadmap item is implemented
- **THEN** The feed backfills from existing stored transcripts, not only from new runs
