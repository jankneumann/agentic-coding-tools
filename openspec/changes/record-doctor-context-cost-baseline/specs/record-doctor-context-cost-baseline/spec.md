## ADDED Requirements

### Requirement: Record the /doctor context-cost baseline

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-04` and is refined by
`/plan-feature` before implementation.

#### Scenario: A committed dated report states the total skill-listing context cost…

- **WHEN** the roadmap item is implemented
- **THEN** A committed dated report states the total skill-listing context cost and names its top contributors

#### Scenario: Skills never triggered in the available transcript history are…

- **WHEN** the roadmap item is implemented
- **THEN** Skills never triggered in the available transcript history are listed as deletion candidates

#### Scenario: Any SessionStart hook flagged as slow is recorded with its measured…

- **WHEN** the roadmap item is implemented
- **THEN** Any SessionStart hook flagged as slow is recorded with its measured duration
