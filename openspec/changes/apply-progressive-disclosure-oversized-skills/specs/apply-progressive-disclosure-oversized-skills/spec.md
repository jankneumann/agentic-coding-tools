## ADDED Requirements

### Requirement: Apply progressive disclosure to the eleven oversized skills

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-15` and is refined by
`/plan-feature` before implementation.

#### Scenario: No SKILL.md exceeds 500 lines

- **WHEN** the roadmap item is implemented
- **THEN** No SKILL.md exceeds 500 lines

#### Scenario: All reference files link directly from their SKILL.md with no nested…

- **WHEN** the roadmap item is implemented
- **THEN** All reference files link directly from their SKILL.md with no nested references

#### Scenario: Reference files over 100 lines carry a table of contents

- **WHEN** the roadmap item is implemented
- **THEN** Reference files over 100 lines carry a table of contents

#### Scenario: Measured per-run context consumption falls for at least one skill…

- **WHEN** the roadmap item is implemented
- **THEN** Measured per-run context consumption falls for at least one skill where a phase is skipped
