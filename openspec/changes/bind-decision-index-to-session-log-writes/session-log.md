4. **The gate keeps checking the decision index** `architectural: project-context-refresh-orchestration` — This removes one cause, not the check. A hand-edited session log, a manual archive move, and any future writer bypassing PhaseRecord all still stale the index. Six firings with one cause and one fix is an argument for closing the cause, never for lowering the check that found it.

- Accepted A lazy dependency from phase_record.py on the index generator over keeping the module dependency-free because resolved at call time and degrading to a warning when absent, so a checkout without the generator still writes its session log
