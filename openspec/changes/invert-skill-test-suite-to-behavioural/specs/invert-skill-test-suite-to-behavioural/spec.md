## ADDED Requirements

### Requirement: Invert the skill test suite from shape assertions to behavioural scenarios

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-18` and is refined by
`/plan-feature` before implementation.

#### Scenario: Frontmatter parsing and reference resolution checks are retained;…

- **WHEN** the roadmap item is implemented
- **THEN** Frontmatter parsing and reference resolution checks are retained; shape assertions are removed

#### Scenario: Each user-invocable skill has at least three behavioural scenarios…

- **WHEN** the roadmap item is implemented
- **THEN** Each user-invocable skill has at least three behavioural scenarios wired into CI

#### Scenario: Total skill test line count falls while measured behavioural…

- **WHEN** the roadmap item is implemented
- **THEN** Total skill test line count falls while measured behavioural coverage rises

#### Scenario: A deliberately broken skill fails its behavioural scenarios

- **WHEN** the roadmap item is implemented
- **THEN** A deliberately broken skill fails its behavioural scenarios
