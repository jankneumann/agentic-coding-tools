## ADDED Requirements

### Requirement: Rescope review convergence from consensus to disagreement routing

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-16` and is refined by
`/plan-feature` before implementation.

#### Scenario: Convergence output distinguishes contested findings from agreed…

- **WHEN** the roadmap item is implemented
- **THEN** Convergence output distinguishes contested findings from agreed findings and routes contested ones to a human queue

#### Scenario: No gate treats unanimous vendor agreement as sufficient evidence of…

- **WHEN** the roadmap item is implemented
- **THEN** No gate treats unanimous vendor agreement as sufficient evidence of correctness on its own

#### Scenario: Routing precision is reported against the seeded-defect set from ri-06

- **WHEN** the roadmap item is implemented
- **THEN** Routing precision is reported against the seeded-defect set from ri-06
