## ADDED Requirements

### Requirement: Rewrite skill frontmatter to what the runtime reads

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-10` and is refined by
`/plan-feature` before implementation.

#### Scenario: No SKILL.md contains a triggers field

- **WHEN** the roadmap item is implemented
- **THEN** No SKILL.md contains a triggers field

#### Scenario: All 74 descriptions state both capability and trigger condition in…

- **WHEN** the roadmap item is implemented
- **THEN** All 74 descriptions state both capability and trigger condition in third person

#### Scenario: The /doctor listing context cost is re-measured and compared against…

- **WHEN** the roadmap item is implemented
- **THEN** The /doctor listing context cost is re-measured and compared against the ri-04 baseline

#### Scenario: Skill-selection accuracy on a held-out set of natural user phrasings…

- **WHEN** the roadmap item is implemented
- **THEN** Skill-selection accuracy on a held-out set of natural user phrasings does not regress
