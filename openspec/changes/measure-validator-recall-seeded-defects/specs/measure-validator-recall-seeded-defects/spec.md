### Requirement: Measure validator recall with a seeded-defect harness

The system SHALL deliver the outcomes below. This requirement is a preliminary
sketch generated from roadmap item `ri-06` and is refined by
`/plan-feature` before implementation.

#### Scenario: Each review skill reports a recall figure against the 40-defect set

- **WHEN** the roadmap item is implemented
- **THEN** Each review skill reports a recall figure against the 40-defect set

#### Scenario: Defect categories are traceable to real observations from the…

- **WHEN** the roadmap item is implemented
- **THEN** Defect categories are traceable to real observations from the failure record

#### Scenario: Seeded defects are injected reproducibly from a committed manifest

- **WHEN** the roadmap item is implemented
- **THEN** Seeded defects are injected reproducibly from a committed manifest

#### Scenario: Recall is reported per defect category, not only in aggregate

- **WHEN** the roadmap item is implemented
- **THEN** Recall is reported per defect category, not only in aggregate
