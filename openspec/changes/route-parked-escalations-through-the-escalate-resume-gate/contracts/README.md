# Contracts

This change adds no new wire, database, or event schema. It composes the existing supervised-dispatch result, delegated-attempt, gate-decision, and supervisor-record contracts. `ExecutionAdapter.apply` retains its exact existing Python return shape and keys. The separate `ExecutionAdapter.route_parked_escalations` operation returns a list with at most one entry per named-batch attempt. Each entry contains exactly `dispatch_id` and `outcome` (`proceed`, `blocked`, or `already_routed`); `proceed` may add `lease_generation`, while `blocked` adds only a supervisor-record-normalized `pending_gate`. No entry exposes a transcript, raw approval payload, or child-provided reason.
